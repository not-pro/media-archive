# Media Archive

Десктопное приложение для macOS и Windows на Tauri/Rust, которое сохраняет авторизованные медиаматериалы для офлайн-просмотра.

## Возможности и ограничения

- Материалы с открытым и ограниченным доступом — только если текущая сессия действительно открывает доступ и локальный компонент получает незашифрованные форматы.
- Сессия подключается импортом `cookies.txt` в формате Netscape. Пароль не используется. Файл фильтруется и сохраняется в системной связке ключей; расшифрованная копия создаётся только во временной папке на время операции.
- Сохранение одного материала в MP4, выбор максимального разрешения, отмена и продолжение `.part`.
- DRM/Widevine, получение PO Token, плейлисты, каналы, live, audio-only и субтитры не поддерживаются.

Доступ к просмотру не гарантирует возможность сохранения. Использование стороннего загрузчика может нарушать правила сервиса и привести к ограничениям аккаунта. Не передавайте файл cookies другим людям.

## Разработка

Требуются Node.js 22+, Rust 1.90+ и системные зависимости Tauri. Node.js нужен только для сборки и проверок, не для работы готового приложения. Sidecar-файлы скачиваются из pinned-релизов и проверяются по SHA-256.

```sh
npm ci
npm run sidecars
npm start
```

Проверки и сборка для текущей ОС/архитектуры:

```sh
npm test
npm run dist
```

Готовые установщики создаются в `src-tauri/target/release/bundle/`. Для получения sidecar-файлов всех поддерживаемых целей используйте `npm run sidecars:all`. Windows-сборка выполняется на Windows; CI дополнительно собирает macOS arm64/x64 и Windows x64.

Для реального теста загрузчика с разрешённой ссылкой:

```sh
MEDIA_LIVE_URL="https://…" cargo test --manifest-path src-tauri/Cargo.toml --test live -- --ignored
```

## Компоненты

- Tauri 2.12.4 и Rust backend
- yt-dlp 2026.10.26
- Deno 2.9.8
- FFmpeg/ffprobe 6.0 из релиза `b6.1.1` в `eugeneware/ffmpeg-static`
